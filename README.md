# 🔢 NumPy Learning Journey

Welcome to my NumPy practice repository! This space documents my hands-on progress learning **NumPy (Numerical Python)**—the core library for high-performance scientific computing and data science in Python.

---

## 📂 Repository Structure

The code is organized topic-by-topic to track my progression from fundamentals to advanced array operations:

* **`01-basics/`** - Array creation, data types (`dtype`), shapes, and basic attributes.
* **`02-indexing-and-slicing/`** - Multi-dimensional slicing, boolean masking, and fancy indexing.
* **`03-vectorization-and-math/`** - Universal functions (ufuncs), aggregate operations, and replacing slow loops with vectorized code.
* **`04-broadcasting/`** - Understanding NumPy's broadcasting rules for arithmetic operations on arrays of different shapes.
* **`05-linear-algebra-and-stats/`** - Matrix multiplication (`np.dot`, `@`), statistics, and random number generation.
* **`projects/`** - Small practical scripts and mini-challenges combining these concepts.
